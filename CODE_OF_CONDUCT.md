# Code of conduct

Be respectful. Harassment, personal attacks, and sexualized language are not acceptable in issues, pull requests, or any other project space.

Report a problem by [opening a private security advisory](https://github.com/SokolskyNikita/cross-domain-iframe-communication/security/advisories/new) or, when it is not a security issue, [opening an issue](https://github.com/SokolskyNikita/cross-domain-iframe-communication/issues).
